# 🤖 FAQ Chatbot

## 📌 Project Overview

The FAQ Chatbot is an AI-powered chatbot designed to answer frequently asked questions by matching user queries with predefined responses. It uses Natural Language Processing (NLP) techniques such as tokenization, lemmatization, TF-IDF vectorization, and cosine similarity to understand user input and provide relevant answers.

This project helps automate customer support and information retrieval by providing quick and accurate responses to common questions.

---

## 🚀 Features

- Interactive chatbot interface
- Answers Frequently Asked Questions (FAQs)
- Natural Language Processing (NLP)
- TF-IDF based text vectorization
- Cosine similarity for response matching
- User-friendly and lightweight implementation
- Fast and efficient response generation

## 🧠 Working Principle

1. Load FAQ data from a JSON file.
2. Preprocess text using tokenization and lemmatization.
3. Convert text into numerical vectors using TF-IDF.
4. Calculate cosine similarity between user query and stored FAQs.
5. Return the most relevant answer.
